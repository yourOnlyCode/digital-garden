# Matthew Mullin — capsule garden & sketchbook

A personal site and digital garden. The home page is a single line with every section on it.

## Run it

```bash
npm install
```

```bash
npm run dev
```

Then open http://localhost:3000.

## Edit it

Sections, their descriptions and their images live in `src/content/sections.ts`. Images are square crops in `public/prints/`, taken from the Cleveland Museum of Art's Open Access collection (CC0).
